# מחשבון השוואת השקעות — Investment Comparison Calculator

אפליקציית רשת מתקדמת בעברית (RTL) להשוואה דינמית בין שני תרחישי משיכה מקרן השתלמות.

---

## 📌 סקירה כללית

המחשבון מסייע לקבל החלטה פיננסית מושכלת לגבי כדאיות המשך החזקת **קרן השתלמות** (שחלק מהפקדותיה היו מעל תקרת הפטור ממס) לעומת משיכה חד-פעמית, תשלום מס רווחי הון, והשקעה מחדש ב**תיק השקעות חייב במס** (או כלי השקעה רגיל).

### התרחישים הנבדקים:

- **תרחיש א׳ — משיכה הדרגתית מקרן השתלמות**: משיכה חודשית (צמודת אינפלציה) ישירות מקרן השתלמות לפי סדר FIFO (הפקדה ותיקה ראשונה). בכל משיכה מחושב החלק היחסי הפטור והחייב במס (25% על החלק החייב).
- **תרחיש ב׳ — משיכה חד-פעמית + השקעה מחדש בתיק חייב**: פדיון מלא מיידי של קרן השתלמות, תשלום המס הנדרש, והשקעת הנטו בתיק השקעות. מתיק זה מבוצעת אותה משיכה חודשית (צמודת אינפלציה) לפי תנאי התשואה, דמי הנהול ושיעור המס של הכלי החדש (למשל 25%).

---

## 🌟 תכונות עיקריות

- **מנוע חישובים מדויק (Pure JS)**:
  - מודל FIFO מלא לכל הפקדה (שיעור פטור יחסי לכל הפקדה שנצברה).
  - חישוב תשואה ודמי ניהול ברמה חודשית.
  - התאמת משיכה חודשית לאינפלציה שנתי/חודשית.
  - טבלת תקרות שכר והפקדה היסטוריות לשכירים (1995–2026+) לצורך חישוב אוטומטי של אחוז הפטור ממס בעת הזנת הפקדות שנתיות.
- **עיצוב פרימיום (Dark Glassmorphism)**:
  - ממשק משתמש יוקרתי בעברית מלאה (RTL) עם גופני Heebo.
  - אפקטי זכוכית (`backdrop-filter: blur`), תאורת אווירה (Ambient Glows) ואנימציות מודרניות.
  - התאמה מלאה לכל גודל מסך (Desktop, Tablet, Mobile).
- **הצגת נתונים ויזואלית ואינטראקטיבית**:
  - כרטיסי סיכום השוואתיים + תגית "התרחיש המנצח" המדגישה את החיסכון הכלכלי.
  - 4 גרפים אינטראקטיביים מבית Chart.js:
    1. **יתרת קרן**: מעקב אחר יתרת הנכסים לאורך זמן.
    2. **מס מצטבר**: תשלומי המס המצטברים בכל תרחיש.
    3. **נטו מצטבר**: סך המזומן שזורם לידי המשתמש.
    4. **פירוט מס/נטו**: דיאגרמת טבעת (Doughnut) להשוואת התפלגות התקבולים.
  - טבלת פירוט חודשי מלאה עם אפשרות מעבר בין תרחישים וכפתור "הצג עוד".

## 📊 דוגמת בדיקה (Benchmark Case)

הזנת נתוני דוגמה:
- יתרה נוכחית: **₪500,000** (קרן מקורית **₪300,000**, 70% פטור ממס)
- תשואה שנתית צפויה (כלי א׳): **6%** | דמי ניהול: **0.5%**
- משיכה חודשית מבוקשת: **₪5,000** | אינפלציה: **2%**

|---|---|---|---|
| **סה״כ מס ששולם** | ₪26,157.11 | ₪46,994.35 | ₪20,837 (לטובת א׳) |
| **סה״כ נטו שהתקבל** | ₪622,604.55 | ₪580,983.09 | **₪41,621 (לטובת א׳)** |

| **שיעור מס אפקטיבי** | 4.03% | 7.67% | **-3.64%** |
